# На опережение

Ведение хориоамнионита в родах: решения до температуры. Приложение для родблока в одном файле `index.html`, без сборки и без сервера.

## Что внутри

- **Мастер** — пять зон (от обычных родов до сепсиса) и план по анализам, антибиотикам, инфузии и парацетамолу.
- **Кворум** — серая зона: повестка маркеров, алиби по маркеру, голоса (плод, мать, матка и воды, время), сетка по сроку, точка T с отсчётом по кинетике маркера.
- **Тренды** — ежечасные измерения, графики и зона по каждой строке.
- **Бандл ИАИ** — таймер от «времени ноль», расчёт доз (гентамицин по идеальной или скорректированной массе), следующие дозы, тактика после родов, передача неонатологу.

## Кворум — единая сетка

Голос плода → антибиотики при любом сроке. До 34 недель хватает одного голоса, с 34 недель нужно два голоса.

## Локальная настройка

После естественных родов при выставленном ХА антибиотики не отменяются: та же схема до 48 ч без лихорадки после родов. После кесарева сечения — не меньше, с анаэробным покрытием.

## Статус

Концепция для обсуждения, не валидирована. Не заменяет КР «Инфекции амниотической полости и плодных оболочек (хориоамнионит)» (2023) и протокол учреждения. Дозы — сверить с формуляром и инструкцией.

Данные хранятся только на устройстве (localStorage), без ФИО. Кнопка «Новая пациентка» стирает всё.
